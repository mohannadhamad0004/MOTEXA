# Current-screen audit — refinement baseline

- Footer was absolutely positioned over scroll content: confirmation CTA, request details, specialties and form fields were visibly obscured at 390×844.
- A new capsule replaced the existing shared FloatingRoleTabs. Restore the original named tabs and animated cutout without altering routing.
- Great Vibes editorial titles were changed to ordinary sans-serif in public introduction and role selection. Restore original display typography; retain Manrope/Cairo for readable functional text.
- Home and Garage reused the same full vehicle card; booking repeated another car stage before the form. Differentiate hero, collection, and concise booking context.
- Captions and metadata frequently used 8–10px. Raise useful labels to 12px, body copy to 13–14px and form input text to 16px.
- The same cockpit image repeated through authentication, specialist profile, tracking and account. Use new context-specific workshop, diagnostic, wheel and interior art; retain honest editorial labels.
- Service mode cards had inconsistent image framing and density. Give workshop/mobile/online different compositions with one visual system and actual API mode values.
- Request progress was a small decorative road. Promote clear numbered service milestones and keep declined/cancelled status explicitly terminal.
- Inline booking validation was absent; only a generic notice appeared above the form.
- Secondary controls were sometimes 38–43px. Preserve at least 44px touch targets; use 48px for owner icon actions.
- Existing functionality remains the baseline. No backend rewrite is needed for this refinement.

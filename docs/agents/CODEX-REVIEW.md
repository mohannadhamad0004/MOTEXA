## Checked and fine (one line each)

- **Route match mobile ↔ backend:** all 199 `api()` calls map to an existing route, method and mount (checked by pattern); status enums match (orders, tow, driver approval, tow stages).
- **Guards:** every router either has a router-level guard (`admin`, `admin-invitations`, `catalog*`, `mechanic-review`, `mechanics`, `provider-onboarding`, `vehicle3d`) or per-route `customer` / `shopSide` / `companySide` / `admin` arrays. Admin tow = `requireTowAdmin`, parts = `requirePartsAdmin`, both check `MANAGE_*` or SUPER_ADMIN. Ownership checks (`ownRequest`, `companyRequest`, `jobFor`, `ownProduct`, order `shop.userId`) are present on every read/write I opened.
- **Pending providers:** `requireApprovedProvider` gates product create/edit/delete, driver add, tow requests, orders, inquiries, portal media (see 14 for trucks).
- **Customer privacy:** tow `customerView` blanks `contactPhone`, never returns driver phone/email/licence, plate masked until assigned; catalog never returns phone/email/documents; storefront photo only for APPROVED shops; private files only owner/matching admin. Live driver point only for the customer's own active job.
- **Transactions:** tow accept/assign/cancel/complete, order accept/deliver/cancel, driver add (with file cleanup on failure), reviews (unique + audit) are all atomic conditional updates; the offer sweeper is idempotent (`updateMany … where status REQUESTED`).
- **Migrations:** no `DROP COLUMN/TABLE`, no `RENAME`, no `SET NOT NULL`; the only `DROP INDEX` is the approved kitPart swap (`20261107090000`); `UPDATE` statements are backfills (`…vehicle3d_provider_lifecycle`, `…managed_vehicle_catalog`, `…tow_driver_profiles` sets existing drivers APPROVED).
- **Mock/fake data:** none on screens; `/dev/*` labs are behind `__DEV__` and a redirect (`garage-lab.tsx:187`, `motion-lab.tsx:228`); seeds refuse production/`ALLOW_DEV_SEED`; Meshy "mock" mode is explicit and never publishes. Remaining placeholder-like UI: items 7, 23 and the customer home "AI diagnosis — Coming soon" row (honest, not a number).
- **Native paths that are right:** `pickPhoto` (no permission prompt, resize 1600 px, HEIC/WEBP/PNG -> JPEG, base64 cached by uri), XHR upload with progress for big bodies, driver add body limit 14 MB, location watch is foreground-only, removed on blur, 5 s / 20 m throttle.
- **i18n:** no hard-coded English found in JSX/placeholders/alerts of the screens I grepped; dev labs aside. The gap is server error text (item 4).
